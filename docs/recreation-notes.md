# 参考片段与复刻设计

参考片段：`claude_剪视频过程motion`，动效片段 ID：`e3ee409a-50f7-4b4a-af27-288226e47a57`。

参考视频为 1280 × 720、30 fps，时长约 30.058 秒。工程采用相同尺寸与帧率，以 900 帧输出 30 秒视频。以下时间段依据参考关键帧整理，用于说明整体节奏；具体动作由组件中的帧时间定义。

## 构图与视觉语言

整体画面是米白色的手绘桌面视频编辑器。上半部由左侧素材或工具面板、居中的竖屏手机预览、右侧调整面板组成；下半部是一条横向时间轴，含视频、文字和紫色音频轨道。深色细线、略有倾斜的边框、柔和纸张底色和手写文字保持插画感。

主导配色为暖米白、炭黑、薄荷绿、黄色、淡紫和陶土红。手机内的四组场景提供较强的色彩对比：深蓝月夜城市、浅黄拉面、薄荷绿柴犬、紫蓝霓虹舞台。标题和拟声词使用高对比描边，出现时伴随轻微放大或弹跳。

字体使用开源 Long Cang 手写字体，保留随附 OFL 许可。界面文字、角色表情、素材场景均由可编辑的 React/SVG 元素重建，参考视频不作为输出画面或背景素材。

## 分段节奏

| 时间（约） | 参考动作 | 重建重点 |
| --- | --- | --- |
| 0–2 秒 | 简短代码窗口引出编辑器，手机预览和面板展开 | 留白、窗口进入、整体缩放与构图稳定 |
| 2–5 秒 | 红色角色从素材区把四组素材放入时间轴，铺设音频 | 拖拽轨迹、角色伸手、素材缩略图依次进入 |
| 5–8 秒 | 播放头移动、拉面片段切分，废片进入垃圾桶 | 红色播放头、切片间隙、切割动作与拟声词 |
| 8–11 秒 | 打开工具并加入翻页或旋转转场 | 手机场景切换、纸页翻折、短促弹性动作 |
| 11–15 秒 | 柴犬片段加“前方高能预警”，撤销后修正文字 | 文本逐步出现、文字轨道、Ctrl+Z 卡片与修正印章 |
| 15–20 秒 | 霓虹舞台调整亮度、饱和度和相关参数 | 滑杆变化、过饱和视觉冲击、回调到柔和颜色 |
| 20–23 秒 | 时间轴添加密集节拍点 | 三角节拍标记、手机内角色舞动、轨道播放 |
| 23–26 秒 | 点击导出，进度变化并显示完成提示 | 伸长手臂、导出按钮、进度与收尾动作 |
| 26–30 秒 | 编辑器退为背景，手机与“30 秒剪完，Opus 5.5”纸卡收尾 | 背景淡化、主体聚焦、手写文字与最后定格 |

## 实现与核验边界

复刻以纯组件和 SVG 重建关键场景及运动，追求构图、视觉语言和动作节奏接近参考。输出是重新绘制的动画，手绘纹理、角色细节与个别动作仍可能存在差异。

`scripts/verify-output.mjs` 只验证最终文件的技术规格。视觉相似度应结合关键帧和完整播放检查，规格通过本身不能证明逐像素一致。
